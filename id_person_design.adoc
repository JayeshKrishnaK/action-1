== Overview

The {module-name} module represents a person’s identity in the face recognition system.
Each IdPerson object stores multiple IdRecord objects for different head poses, as well as cropped images used for recognition and enrollment.

=== Scope

The module:

. Defines a serializable identity representation for face recognition.
. Manages multiple identity records per head pose.
. Supports serialization and deserialization for storage and retrieval.
. Provides compatibility with older serialization formats.

=== Technical Requirements

Serialization must maintain backward compatibility with older formats.

=== Main Operation

The main operations revolve around managing records and images for face recognition, along with serialization.

*Example flow diagrams for `serialize` and `deserialize`*:

. serialize flow

[plantuml]
[.text-center]
----
@startuml
start
:Write records-per-bin counts;
:Write each IdRecord in each bin;
:Write each DbCropData image;
stop
@enduml

[plantuml]
[.text-center]
----
@startuml
start
:Read records-per-bin counts;
:Read IdRecords from each bin;
:Read DbCropData images;
:Set recognition stage to Unknown;
stop
@enduml
----
